# Clone Pictures Studio website

The marketing site for Clone Pictures, a photography studio with three branches in Lagos:

| Branch | Location | WhatsApp |
| --- | --- | --- |
| Yaba | Ozone Cinemas Mall, 11 Commercial Ave, Sabo, Yaba | 0903 818 1728 |
| Leisure Mall, Surulere | Leisure Mall, beside ShopRite, Adeniran Ogunsanya St | 0704 897 8732 |
| Adeniran Ogunsanya, Surulere | Adeniran Ogunsanya St, beside The Place Restaurant | 0808 477 2545 |

It is a static site built by a zero-dependency Node script. It deploys to Render.

```
src/
  index.html          page template (<!--slot:x--> and {{x}} are filled in at build time)
  css/style.css       styles and animations (inlined into the page at build time)
  js/templates.js     HTML templates shared by the build and the browser
  js/main.js          behaviour: slideshow, gallery, lightbox, booking (branch → WhatsApp)
  data/site.json      branches, services, gallery categories, hero/strip picks, SEO copy
  data/photos.json    Cloudinary image manifest (generated by the upload script)
  static/             icons, copied as-is
scripts/
  build.mjs           builds dist/
  serve.mjs           local preview server for dist/
  upload_to_cloudinary.py, sources.json   image pipeline
render.yaml           Render Blueprint (static site, cache + security headers)
```

## Develop

Requires Node 18 or newer.

```
npm run preview      # build, then serve dist/ at http://localhost:5173
```

To change branch details, services or SEO copy, edit `src/data/site.json` and rebuild.

## What the build does

- **Pre-renders** every section into `index.html`, so content shows on the first paint and search engines can read it without running JS.
- **Inlines** the CSS. The JS is fingerprinted as `/assets/app.<hash>.js` and cached for a year.
- **Images:** loads the hero image early. Phones get a portrait crop from Cloudinary, and other images lazy-load in WebP/AVIF at the right size for the screen.
- **Generates SEO files:**
  - canonical, Open Graph and Twitter tags
  - `schema.org` structured data (Organization plus one LocalBusiness per studio, with address, phone and services)
  - `sitemap.xml` (with every photo)
  - `robots.txt`
  - the web manifest
  - a 404 page

`SITE_URL` sets the canonical URL, sitemap and social cards. It defaults to `https://clone-pictures.onrender.com`.

## Deploy on Render

1. In the Render dashboard, choose **New → Blueprint** and select this GitHub repo. Render reads `render.yaml` and creates the `clone-pictures` static site.
2. Every push to `main` redeploys automatically.
3. If you add a custom domain, or Render assigns a different `*.onrender.com` name, update the `SITE_URL` environment variable on the service and redeploy.
4. Submit `https://<your-domain>/sitemap.xml` in Google Search Console. Also set up a Google Business Profile for each studio, which matters most for local search.

## Images

Photos come from the studio's Pixieset gallery and Instagram. They are hosted on Cloudinary under `clone-studio/<category>/`.

To change the selection, edit `scripts/sources.json` and run:

```
# .env (gitignored) must contain CLOUDINARY_URL=cloudinary://<key>:<secret>@<cloud>
python scripts/upload_to_cloudinary.py
```
